# VaiperX ULTRA Panel — เริ่มต้นเรียนโค้ด

## ไฟล์สำคัญ
- index.html = โครงสร้างหน้าเว็บ
- style.css = สี ขนาด ระยะห่าง และหน้าตา
- script.js = การทำงานของปุ่มและ Toggle

## วิธีทดลองแก้เอง
1. เปิด index.html
2. เปลี่ยนข้อความ `VaiperX ULTRA` เป็นชื่อของคุณ
3. เปิด style.css
4. ลองเปลี่ยน `#e6003b` เป็นสีอื่น เช่น `#0066ff`
5. เปิด script.js แล้วลองเปลี่ยนข้อความใน `showToast(...)`
6. บันทึกไฟล์แล้วเปิด index.html ใหม่

## ลำดับที่ควรเรียน
HTML → CSS → JavaScript → Git/GitHub → API → Database

## ข้อควรรู้
ปุ่มในตัวอย่างนี้เป็น UI/demo เท่านั้น ไม่ได้เชื่อมต่อหรือแก้ไขเกมจริง
